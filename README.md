# Ext<sub>𝒜</sub> through t = 350

Interactive Adams chart in `(t-s, s)` coordinates for Ext<sub>𝒜</sub> through internal degree `t = 350`.

The chart includes the additive basis and multiplication by h<sub>0</sub> through h<sub>8</sub>.
h<sub>0</sub>, h<sub>1</sub>, and h<sub>2</sub> are enabled by default; higher actions can be toggled on.
Select a class to inspect its bidegree and incident products.

The site is entirely static and is published with GitHub Pages.
