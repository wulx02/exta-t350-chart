# Ext_A through t = 350

Interactive Adams chart in `(t-s, s)` coordinates for `Ext_A` through internal degree `t = 350`.

The chart includes the additive basis and multiplication by `h0` through `h8`.
`h0`, `h1`, and `h2` are enabled by default; higher actions can be toggled on.
Select a class to inspect its bidegree and incident products.

The site is entirely static and is published with GitHub Pages.
